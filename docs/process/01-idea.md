# Step 1 · Idea

**Prompt (the idea, as stated to Claude):** Build a small full-stack reference web app with Next.js (App Router), React and in-memory SQLite. It is a reference app, not production.

**Product:** a notes app. A user signs up and signs in, then creates, edits and deletes notes, tags them, and searches them.

**Why this idea:** small enough to build on screen, yet it touches every layer: UI, API, database, auth and tests.

**Look and feel (given to the mocks step):** crisp modern SaaS. Neutral greys, one indigo accent, an Inter-style sans, dense but clean, light and dark themes.

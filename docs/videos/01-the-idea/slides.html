Step 1 · The prompt

Build a small full-stack reference web app with Next.js (App Router), React and in-memory SQLite. It is a reference app, not production.

Two qualifiers

Small

The whole app is built on screen, in a video series.

Reference, not production

Show the process, not ship a product. In-memory SQLite: nothing persists across restarts, by design.

The product

A notes app

A user signs up and signs in, then creates, edits and deletes notes, tags them, and searches them.

The entire feature list

Accounts

Sign up, sign in

Notes

Create, edit, delete

Tags

Tag a note

Search

Find a note

No sharing, no collaboration, no sync. Small on purpose.

L1-009 Demo data

Because Selah is a reference app, data shall live in memory, be seeded at startup, reset on every restart, and the app shall say so.

L1-011 Performance

Common actions shall feel immediate on a workspace of over one thousand notes.

L2-016 · Delete a note

Traces to L1-003 dialogs/delete-note: default · busy · failed 6 acceptance criteria 
1. Given an open note, when "Delete note" is chosen, then a dialog titled `Delete "<note title>"?`
   opens, reads "The note and its n tags are removed from your list. You'll have 8 seconds to undo.",
   has Cancel and a "Delete note" danger button, and initial focus is on Cancel.
3. Given the person confirms, when the request is in flight, then the danger button reads
   "Deleting…", is disabled, and Cancel is disabled.
5. Given the request fails, when it fails, then the dialog stays open with "Couldn't delete the note"
   and "The server didn't respond. The note is still in your list.", and the button reads "Try again".
6. Given a note with no tags, when the dialog opens, then it does not mention tags.

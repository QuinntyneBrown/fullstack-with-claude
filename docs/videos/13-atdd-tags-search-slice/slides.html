One page of NoteListItem rows: title, 240-character snippet, tags, times; matching total and a keyset nextCursor on (updated_at, id)

Tags

  • tagsRepo.attachByName: find or create, refuse the eleventh, insert, move updated_at, one transaction
  • tagsRepo.detach and listWithCounts

  • TagChips: "Remove tag <name>" buttons; dashed "Add tag", disabled with its reason at 10 tags

Decisions: picker and URL

A popover, not Dialog

The mocks draw it anchored to "Add tag"; it closes on Escape, outside click and after an attach

The filter lives in the URL

?q= and ?tag=; history.replaceState so typing never round-trips

Decisions: the edges

  • The layout seeds the first page for the URL's filter; no GET /api/tags
  • A malformed page tag is ignored; the API answers 400
  • An empty tag filter shows "0 notes" and a TagEmpty panel

Decisions: details

  • Chips keep attach order (note_tags.rowid)
  • "Clear search" keeps the mock's name on the field and the panel
  • Snippets are 240 characters from the server
  • % matches the seeded recipe and the test's own note: a literal match

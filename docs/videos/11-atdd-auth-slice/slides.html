Sessions

HMAC-SHA-256 of a 32-byte random token; only the hash is stored. lib/repositories/sessions.ts, lib/auth/session.ts

Two windows

2-hour inactivity · 7-day absolute

Cookie

HttpOnly · SameSite=Lax · Path=/ · Secure over HTTPS · 7-day Max-Age

publicRoute()

Health and the harness

route()

Resolves the session first; 401 before the handler or any repository runs. Adds X-Session-Expires-At and Cache-Control: no-store. { touch: false } for reads that must not extend the window.

Sign-in and sign-up

Decisions: who redirects, who navigates

requireUser, not the middleware

Next rewrote a middleware redirect's host to localhost, cross-origin, tripping connect-src 'self' on a prefetch. A relative redirect() stays same-origin.

Actions return, the client navigates

{ status: "ok", redirect } then window.location.assign; an aborted POST shows the unreachable state instead of an error boundary.

Decisions: proving time without waiting

A harness ages sessions

POST /api/harness/session/age moves created_at and last_seen_at into the past; SESSION_INACTIVITY_MS, SESSION_ABSOLUTE_MS

Relative expiresIn

The watcher computes expiresAt = Date.now() + expiresIn, so a controlled browser clock and a real server clock agree

Full stack with Claude · Video 03

Repo, clone and skills

Steps three to five: a public repo, an empty clone, and ten skills in two folders.

Step 3 · Create the repo

gh repo create QuinntyneBrown/selah --public \
  --description "Selah: a small notes app, the reference app for the Full stack with Claude video series"

Decided in one command

Public

A reference app is meant to be read.

Described up front

What it is and what it is for, before anyone opens a file.

Step 4 · Clone it empty

C:\projects> gh repo clone QuinntyneBrown/selah selah
warning: You appear to have cloned an empty repository.

That warning is the point

  • No README, no license, no scaffold
  • Every file arrives through a step in the process
  • Each step has a log: which model, which prompt

An empty clone means nothing arrives from memory.

A skill is a folder with a SKILL.md: how to do one kind of task. A recursive diff between the two folders is empty.

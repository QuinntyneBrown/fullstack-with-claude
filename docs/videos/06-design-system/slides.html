Three tiers

Primitives--palette-*, --font-*: raw values, never used directly by components
Semantic--color-*, --text-*, --space-*, --radius-*, --shadow-*…: what components consume; themes override these
Component--btn-*, --field-*: always alias a semantic token

Primitives with reasons

  --palette-gray-300: #cdd2da;
  --palette-gray-400: #a6adba;
  --palette-gray-450: #878f9d;   /* 3:1 on white and canvas: control edges */
  --palette-gray-500: #667080;   /* 4.5:1 on white and canvas: metadata */
  --palette-gray-600: #5b6370;
  --palette-gray-700: #434a56;

4.5:1 and 3:1 are the WCAG 2.2 AA thresholds; contrast-pairs.json checks every foreground on every background it sits on.
